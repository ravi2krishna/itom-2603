    -> Network Protocols 

        -> Network protocols are a "set of rules" and formats 
        that govern how devices exchange data across a network.

        -> To exchange data we have Type Of Protocols & Ports 

            -> HTTP / HTTPS (HyperText Transfer Protocol) 
            Transmitting Web Data Over Internet.
            HTTP / HTTPS Ports 80 / 443 

            -> SSH Protocol (Secure Shell) is used to 
            communicate with Linux / Unix Servers. 
            We Use SSH Keys(Pair) i.e Public Key & Private Key. 
            SSH Port is 22

            -> SNMP Protocol(Simple Network Management Protocol)
            Used for Monitoring Network Connected Devices 
            (Routers, Switches, Firewalls etc).
            SNMP Port is 161/162 

    
    
    -> Key Modules / Components Of ITOM 


        -> CMDB - Configuration Management Database 

            -> The Backbone Of ITOM.
            All Discoverd Assets and their Relationships 
            are configured here as Configuration Items (CI's)

        -> Configuration Items (CI's)

            -> Any Asset that needs to be Managed i.e 
            Server, Application, Network Device etc 

        -> Discovery 

            -> The Process Of Automatically Identifying and Populating 
            CI's into CMDB. We Use MID Server for Discovery Process. 

        -> Service Mapping 

            -> Creates a Map, Linking Business Services With 
            all Infrastructure Components.    

        -> Event Management 

            -> Collects Alerts From External Monitoring Tools
            (Nagios, Prometheus, Zabbix etc) and correlates 
            them into actionable Alerts.  


Class - 3
-----------

    -> CMDB - Configuration Management Database 

        -> Configuration Management Database(CMDB) is a centralized location that 
        functions as a data warehouse, organizing information about your IT environment.
        CMDB Clarifies the Relationships between hardware, software and network Components. 

        -> CMDB is the backbone of ServiceNow ITOM.    

        -> CMDB is the Master inventory of ServiceNow.

        -> Every Server, Every Application, Every Database, Every Business Service
        you own live as a record in CMDB.

    -> Configuration Items (CI's)

        -> Configuration Items (CI's) are like atoms of CMDB 

        -> A Configuration Items (CI) in servicenow is a digital record within 
        CMDB representing any manageable IT Component. 

        -> CI's Track Infrastructure Details (Manufacturer, Location, Serial Numbers) 
        to support ITIL Process.

        -> Any Configuration Item has three things 

            -> Class (What Type Of Asset is it)

            -> Attributes (Properties Of Assets)

            -> Relationships (Connection With Other Assets)

    -> Relationships 

        -> A Relationship in ServiceNow is a Connection between 
        Multiple Configuration Items (CI's) which defines 

            -> How CI's Interact with each other 

            -> How CI's Depend On each other

                -> Runs On 

                -> Used By 

                -> Depends On 

                -> etc 

            -> NOTE: The Relationships are Automatically Discoverd using "Discovery Process"
